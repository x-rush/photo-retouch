# 调色知识库（Color Grading Playbook）

> 写调色指令时的专业依据。向用户描述调色方案时用这里的语言；生成提示词时把这些术语转成"画面描述"。
> 依据：人像调色行业惯例（HSL 肤色科学、色分离冷暖、明度先行顺序）+ 实测。

## 调色总顺序（先明度后色相）

1. **明暗层次**：曝光 → 对比 → 高光/阴影（先把"骨架"立起来）
2. **白平衡**：去黄/去绿/去品红偏色（环境光污染源逐一清）
3. **色彩**：HSL 逐色相调整 → 分离色调（高光/阴影各自加色）
4. **肤色最后统一**：脸/颈/手一致（人像的命门）

## 肤色科学（HSL 语言）

- 肤色主要由 **橙色/黄色** 色相承载 → 人像发黄发暗时：**橙黄降饱和 + 提明度**（不是加曝光）
- 泛红（脸颊/关节）：红色相降饱和或微移色相
- 通透感 = 去掉肤色的灰蒙（黑色色阶微降 + 鲜艳度加饱和度减）
- 高级感肤色 = 偏橙红、低饱和、明度适中（拒绝橙黄和高饱和"土气"）

## 风格配方库（写"风格块"时选用）

| 风格 | 画面语言（可直接写进提示词） |
| --- | --- |
| 日系清新 | 曝光微提、低对比、低饱和、青蓝阴影、肤色透白、整体明亮空气感 |
| 韩系干净 | 色温微冷、肤色白皙均匀、背景去杂色、低饱和高明度 |
| 胶片复古 | 阴影带青/褪色黑位、高光偏暖黄、颗粒感、饱和度分层（红绿存、蓝黄压） |
| 欧美高级感 | 低饱和低明度、肤色橙红、暗部带色（teal-orange 分离）、对比硬朗 |
| 港风复古 | 高对比、暖黄主调、肤色浓郁、红绿撞色 |
| 国风清透 | 压黄褐、木色沉静、远景冷青空气感、肤色红润白皙（古镇实测版） |

## 冷暖分离（sep­aration）万能公式

**高光加暖（橙黄）、阴影加冷（青蓝）** → 画面立即有层次和电影感。
写进提示词的说法："highlights lean warm amber, shadows carry subtle teal, gentle warm-cool separation"。

## 写调色指令的纪律（生成式特化）

- 把 HSL 术语翻译成**画面描述**："橙色降饱和提明度" → "skin tones brightened and desaturated toward porcelain warmth"
- 每次只锁定一个风格配方，不要混（"日系+胶片+欧美"= 色彩事故）
- 先说全局（影调/对比/色温），再说局部（肤色/环境色），最后说细节（高光溢出、暗部呼吸感）
